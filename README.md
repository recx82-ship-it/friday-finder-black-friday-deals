Black Friday & Cyber Monday 2026 deals, checked by hand — 72 real deals from Amazon, Best Buy, Walmart, Amazon UK, John Lewis, Currys and Argos, each with its store, a link to the product there, sale price, usual price, discount and the time its price was checked. Every deal carries an honest verdict — record low, standout, strong, decent or routine — with the evidence for it. Search and filter by category, store and discount; sort by biggest discount, biggest cash saving, lowest price or name. Static files, no build step, no network request at runtime.

## Run it

```sh
node serve.mjs
# open http://localhost:8080
```

## Hand in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `app/` and `screenshots/` to `out/` and writes `out/dossier.json`.
